# Fiche de Synthèse : Les Piliers de GitHub

### 1. Programmation collaborative et gestion du code

* **Référentiels (Repositories)** : Organisation et hébergement des projets de code 2.
* **Demandes de tirage (Pull Requests)** : Outil central pour proposer des modifications, effectuer des revues de code et valider l'intégration avant fusion 2.
* **Environnements en ligne (Codespaces)** : Configuration d'espaces de développement hébergés dans le cloud 1.
* **Discussions** : Espaces **GitHub Discussions** pour échanger de manière communautaire ou en équipe autour d'un projet 2.

### 2. Automatisation et DevOps (CI/CD)

* **GitHub Actions** : Automatisations des workflows de développement, d'intégration continue et de déploiement continu (CI/CD) 2.
* **GitHub Packages & Pages** : Gestion et publication de paquets/dépendances, ainsi que l'hébergement de sites web statiques 2.

### 3. Sécurité et qualité du code

* **Détection des vulnérabilités** : Outils intégrés pour rechercher et corriger automatiquement les failles de sécurité dans le code 2.
* **Protection des secrets** : Sécurisation des clés d'accès et des identifiants sensibles 2.
* **Chaîne d'approvisionnement** : Contrôle des dépendances et maintien de la qualité du code à grande échelle 2.

### 4. Planification et gestion de projets

* **Suivi du travail** : Organisation des tâches et suivi des fonctionnalités grâce à **GitHub Issues** et aux tableaux **Projects** 3.
* **Recherche** : Moteur de recherche interne pour retrouver facilement du code, des projets ou des tickets 3.

### 5. Intelligence Artificielle intégrée

* **GitHub Copilot** : Assistance au développement via un agent IA, disponible en ligne de commande (Copilot CLI) ou intégré dans les workflows avec des tutoriels et bibliothèques de personnalisation 2.

### 6. Écosystème, Outils et Administration

* **Applications clientes** : Interfaçage via **GitHub CLI**, **GitHub Desktop** et **GitHub Mobile** 2, 3.
* **Gestion d'équipe et entreprise** : Structuration via les **Organisations**, la gestion des accès d'entreprise et les politiques d'administration 3.
* **Extensibilité** : Intégrations personnalisées à l'aide d'**Applications**, de **Webhooks** et d'**API (REST et GraphQL)** 2, 3.
* **Soutien communautaire** : Fonctions d'engagement avec **GitHub Sponsors**, **GitHub Education** et des programmes pour les associations 3.

*Note : Vos sources actuelles fournissent l'arborescence des fonctionnalités de GitHub Docs, mais ne détaillent pas les commandes Git sous-jacentes (comme git commit ou git push).*

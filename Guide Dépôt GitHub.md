**Guide Dépôt GitHub**

Voici la procédure pas à pas pour créer un **repository** (dépôt) sur GitHub, basée sur la documentation officielle :

**🔧 1. Via l'interface Web (****[GitHub.com](https://GitHub.com)****)**

**Accéder au formulaire** : Connectez-vous à GitHub. Dans le coin supérieur droit, cliquez sur l'icône `+` (menu déroulant), puis sélectionnez **Nouveau référentiel** (*New repository*).

**Nommer le dépôt** : Saisissez un nom pour votre projet dans le champ *Repository name* (par exemple : `mon-premier-projet`).

**Ajouter une description** *(facultatif)* : Indiquez en quelques mots l'objectif de votre projet.

**Choisir la visibilité** :

**Public** : Votre code sera visible par tout le monde.

**Privé** : Seul vous (et les personnes que vous invitez) pourrez y accéder.

**Initialiser le dépôt** :

Cochez **Ajouter un fichier README** (*Add a README file*). Ce fichier servira de page d'accueil à votre projet.

*(Optionnel)* Choisissez un modèle de `.gitignore` ou une licence.

**Finaliser** : Cliquez sur le bouton vert **Créer le dépôt** (*Create repository*).

--------------------------------------------------------------------------------

**💻 2. Via la ligne de commande (GitHub CLI)**

Dans votre terminal, naviguez vers votre dossier de travail.

Exécutez la commande : `gh repo create`

Sélectionnez **Create a new repository on GitHub from scratch**.

Suivez les instructions interactives pour définir le nom, la visibilité et cloner le dépôt localement.

**Supprimer un dépôt GitHub**

Voici la procédure pas à pas pour **supprimer un dépôt (repository)** sur GitHub, basée sur la documentation officielle :

**⚠️ Avertissements préalables**

**Droits d'accès** : Vous devez être propriétaire du compte ou disposer des autorisations d'administrateur sur le dépôt.

**Impact** : La suppression efface définitivement le code, les tickets (*issues*), le wiki, les demandes de tirage (*pull requests*) et les paramètres. Pour un dépôt privé, elle supprime également toutes ses duplications (*forks*).

--------------------------------------------------------------------------------

**🗑️ Étapes pas à pas pour supprimer un dépôt**

**Accéder au dépôt** : Sur [GitHub.com](https://GitHub.com), rendez-vous sur la page principale du dépôt que vous souhaitez supprimer.

**Ouvrir les paramètres** : Dans le menu d'en-tête sous le nom de votre dépôt, cliquez sur l'onglet **Paramètres** (*Settings*). *(Si vous ne voyez pas cet onglet, vous ne disposez pas des privilèges d'administrateur).*

**Accéder à la Zone de Danger** : Dans l'onglet **Général** (*General*), faites défiler la page tout en bas jusqu'à la section **Danger Zone** (*Zone de danger*).

**Lancer la suppression** : Cliquez sur le bouton **Supprimer ce dépôt** (*Delete this repository*).

**Prendre connaissance des impacts** : Cliquez sur **Je souhaite supprimer ce dépôt** (*I want to delete this repository*), puis validez les avertissements d'impact.

**Confirmer le nom du dépôt** : Pour éviter toute suppression accidentelle, saisissez le nom exact du dépôt demandé dans le champ de texte (sous la forme `votre-identifiant/nom-du-depot`).

**Finaliser** : Cliquez sur le bouton de confirmation **Supprimer ce dépôt**.
